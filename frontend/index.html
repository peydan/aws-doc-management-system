Amazon Bedrock AI Auto-Enrichment Guide

        

        
      

      

        

          Automated metadata enrichment executes asynchronously in the background via Amazon Bedrock (Amazon Nova 2 Lite) and Amazon SQS, decoupled from direct uploads (< 200ms).
        

        
        

          
            

              Lifecycle Event / Scenario
              Triggers AI?
              Architectural Reason & Governance Invariant
            

          
          
            

              New Document Upload (Rev 1)
              YES
              DynamoDB Stream INSERT event dispatches to SQS ➔ Bedrock scans text, extracts missing fields, and detects PII ➔ Bumps revision 1 ➔ 2 via OCC.
            

            

              skip_enrichment: true
              NO
              Cost guardrail. Bypasses Bedrock invocation completely (0 tokens consumed, no SQS enqueue).
            

            

              Pre-populated Identifiers
              PARTIAL
              If loan_number is already provided, attribute extraction skips to save tokens; only PII safety check runs.
            

            

              Subsequent Page Additions (v2+)
              NO
              Binary version mutation. Generates new WORM S3 VersionId but preserves established metadata annotations.
            

            

              Manual Metadata Update (PATCH)
              NO
              Direct user updates via DynamoDB OCC are authoritative and immutable to the LLM.
            

            

              Sensitivity & Clearance Roles
              LOCKED
              confidentiality_tier and minimum_clearance_role are strictly governed by the uploader. AI can NEVER modify or downgrade them.
